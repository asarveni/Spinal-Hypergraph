# Spinal-Hypergraph

This repository contains the implementation, configuration, and supplementary material for the JMIR article titled:

**"Spinal-Hypergraph Learning for Biomedical Data"**

The content here is provided for transparency, reproducibility, and review purposes only.

Installation and Running in Jupyter Notebook

To set up the project and run it using Jupyter Notebook, follow these steps:

1. Clone the repository:

git clone https://github.com/asarveni/Spinal-Hypergraph.git
cd Spinal-Hypergraph

2. (Optional) Create and activate a virtual environment (recommended):

conda create -n spinal-env python=3.9
conda activate spinal-env


3. Install required packages:

pip install -r requirements.txt


4. Start Jupyter Notebook:

jupyter notebook


5. Open the notebook file (.ipynb) in the repository and run the cells step-by-step
